# Vida Saudável

O projeto **Vida Saudável** é uma landing page desenvolvida com HTML e CSS voltada para incentivar hábitos saudáveis e melhorar a qualidade de vida das pessoas.

A plataforma apresenta informações sobre benefícios da saúde física e mental, além de sugerir exercícios simples, como alongamentos, respiração guiada e caminhadas leves. O site também possui páginas de login e cadastro com design moderno e responsivo.

## Funcionalidades

- Página inicial moderna e responsiva
- Seção de benefícios para saúde e bem-estar
- Área de exercícios recomendados
- Sistema visual de login e cadastro
- Navegação simples e intuitiva
- Layout adaptado para dispositivos móveis

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## Objetivo

O objetivo do projeto é praticar desenvolvimento front-end criando uma interface moderna, agradável e acessível para usuários interessados em saúde e bem-estar.
